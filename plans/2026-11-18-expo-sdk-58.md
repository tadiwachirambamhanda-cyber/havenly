# Plan: move the app to Expo SDK 58 so the phone's Expo Go opens it

Branch: `chore/expo-sdk-58`. Written by the Chief Architect (package.json, app.json, App-level files).

## Goal
Scanning the Expo QR code on a phone opens the app. The App Store's Expo Go moved to SDK 58, and the app was on SDK 57, so Expo Go refused it ("not compatible").

## Steps
1. `npx expo install expo@^58` then `npx expo install --fix` (React Native 0.88, React 19.3, Reanimated 4.7, and every Expo package to its SDK 58 version).
2. Fix what the new types break: ScrollView and TextInput ref types (`EditResidenceScreen`, `SignInToContinueScreen`), the WebView typing on the Map (`MapScreen`).
3. Fix what the new runtime breaks (found by running it): the launch animation's spring never finishes on web under React Native 0.88, so the app hung on the launch screen. It now uses timed animations plus a 4-second safety timer.
4. Checks: typecheck, lint, tests, expo-doctor, `expo export --platform all` (web, iOS and Android bundles), and a walk through the demo on the new SDK.

## Files
`package.json`, `package-lock.json`, `app.json` (SDK 58 adds two plugin entries), `src/components/LaunchAnimation.tsx`, `src/screens/EditResidenceScreen.tsx`, `SignInToContinueScreen.tsx`, `MapScreen.tsx`.

## Checks
1. typecheck, lint (no warnings), 93 tests, expo-doctor, export for web, iOS and Android all pass.
2. Production web build and dev server: the launch animation finishes, the demo opens on Housing, the four tabs work.
3. On the phone: open Expo Go (update it from the App Store if it asks), scan the QR code from `npx expo start`, and the app opens. (Owner check: not possible from here.)

## What could break
A React Native upgrade can change behaviour that only shows at runtime. Found and fixed: the launch spring. Not yet seen on a phone: Reanimated 4.7, the Map's WebView, video, location and the image picker. Vercel will build the web app on the new SDK when this merges.

## Not doing
New features, SDK 59 or a development build, Sentry or sign-in changes.
